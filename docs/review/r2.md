## Deliberate scope cut → kernel fast-follow

Object put/get is omitted: DoRaw buffers responses with a 100 MiB cap,
which is wrong for object transfer. Kernel needs a streaming raw
primitive (io.Reader body, streamed response) before `cf r2 object cp`
lands. Tracked as maintainer work, not implementer debt.
